# دانلودر اینستاگرام

پروژه اندرویدی مستقل (WebView + DownloadManager) با رابط فارسی.

## ساخت APK
با هر push در مسیر `instagram-downloader/**` یا اجرای دستی workflow با نام **Build Instagram Downloader APK**، نسخه debug ساخته می‌شود. فایل خروجی در GitHub Actions به‌صورت artifact با نام `instagram-downloader-debug` قرار می‌گیرد.

## وضعیت عملکرد دانلود
رابط کاربری، اعتبارسنجی لینک اینستاگرام و ذخیره فایل در پوشه Downloads پیاده‌سازی شده است. استخراج لینک مستقیم به یک نمونه API سازگار با Cobalt نیاز دارد. در تنظیمات برنامه نشانی نمونه‌ای را وارد کنید که مالک آن هستید یا اجازه استفاده از آن را دارید. برنامه به حساب کاربری یا رمز عبور اینستاگرام نیاز ندارد و محتوای خصوصی را دور نمی‌زند.

APIهای میزبانی‌شده عمومی ممکن است دسترسی را محدود کنند؛ برای استفاده پایدار، نمونه شخصی را طبق مستندات رسمی Cobalt میزبانی کنید.
