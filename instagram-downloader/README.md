# دانلودر اینستاگرام

پروژه اندرویدی مستقل (WebView + DownloadManager) با رابط فارسی، بدون تبلیغات.

## ساخت APK
با هر push در مسیر `instagram-downloader/**` یا اجرای دستی workflow با نام **Build Instagram Downloader APK**، نسخه debug ساخته می‌شود. فایل خروجی در GitHub Actions به‌صورت artifact با نام `instagram-downloader-debug` قرار می‌گیرد. برای ساخت APK دیگر به کلید تپسل نیاز نیست.

## احراز عضویت بله
پیش‌نمایش رسانه قبل از احراز عضویت در دسترس است؛ اما هر بار که کاربر دکمه دانلود را می‌زند، برنامه او را با یک nonce تصادفی به `@downloader_instagram_bot` می‌فرستد. ربات در همان لحظه عضویت در `https://ble.ir/downloader_instagram` را با متد `getChatMember` بررسی می‌کند. در صورت عضویت، لینک بازگشت nonceدار به برنامه ارسال می‌شود و برنامه فقط همان درخواست در انتظار را ادامه می‌دهد. وضعیت عضویت به‌صورت دائمی cache نمی‌شود؛ خروج از کانال باعث رد شدن دانلود بعدی می‌شود.

برای راه‌اندازی ربات، سرویس جداگانه Render را طبق `../bale-bot/README.md` با Root Directory برابر `bale-bot` ایجاد و متغیرهای محیطی را تنظیم کنید. ربات باید مدیر کانال باشد. توکن ربات فقط در Render Environment قرار می‌گیرد و نباید در مخزن ثبت شود.

## وضعیت API دانلود
استخراج لینک مستقیم همچنان به سرویس Cobalt سازگار نیاز دارد. سرویس فعلی نمونه در `https://tapsell-html-apk.onrender.com` باید جداگانه از نظر Live بودن و پاسخ واقعی تست شود. API عمومی یا بدون محدودیت را برای انتشار عمومی استفاده نکنید. محتوای عمومی یا محتوایی را دانلود کنید که اجازه ذخیره آن را دارید؛ برنامه محتوای خصوصی را دور نمی‌زند.

Render رایگان ممکن است پس از بی‌کاری به خواب برود. پیش از انتشار، API و مسیر کامل پیش‌نمایش تا ذخیره در گالری را روی دستگاه واقعی آزمایش کنید.
