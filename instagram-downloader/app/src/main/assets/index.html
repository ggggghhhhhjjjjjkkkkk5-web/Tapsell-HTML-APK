دانلودر اینستاگرام

ذخیره ویدئو، ریلز و عکس

لینک اینستاگرام را وارد کن

لینک پست، ریلز یا ویدئوی عمومی را جای‌گذاری کن و فایل را در گوشی ذخیره کن.

فقط محتوای عمومی یا محتوایی را دانلود کن که اجازه ذخیره آن را داری. ورود به حساب اینستاگرام در این برنامه درخواست نمی‌شود.

تنظیم سرویس پردازش لینک

برای فعال شدن استخراج لینک، نشانی یک نمونه API سازگار با Cobalt که اجازه استفاده از آن را داری وارد کن. سرویس‌های عمومی ممکن است محدودیت یا قطعی داشته باشند.
